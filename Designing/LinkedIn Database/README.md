# LinkedIn Database

Author: Caroline Mildred Gomes

## Overview

A relational database design inspired by LinkedIn.

The database stores:

- Users
- Schools
- Companies
- Professional Connections
- Educational History
- Employment History

## Technologies

- SQLite
- SQL
- Relational Database Design

## Skills Demonstrated

- Schema Design
- Many-to-Many Relationships
- Foreign Keys
- Data Integrity
- Professional Network Modeling

## Sample Data

Users:
- Alan Garber
- Reid Hoffman

School:
- Harvard University

Company:
- LinkedIn

## Learning Outcomes

This project demonstrates how large professional networking platforms can organize users, education history, employment records, and social connections using relational databases.
