# Union Square Donuts Database

Author: Caroline Mildred Gomes

## Overview

A relational database designed for Union Square Donuts.

The system manages:

- Ingredients
- Donuts
- Customers
- Orders
- Inventory Relationships

## Technologies

- SQLite
- SQL
- Relational Database Design

## Skills Demonstrated

- Database Modeling
- Many-to-Many Relationships
- Junction Tables
- Customer Order Tracking
- Inventory Management

## Sample Scenario

Customer:
Luis Singh

Order #1

- 3 Belgian Dark Chocolate
- 2 Back-To-School Sprinkles

## Learning Outcomes

This project demonstrates how a bakery or restaurant can use relational databases to manage inventory, menu items, customer history, and online orders.
