## 📌 Project Overview
This project is a relational database system built using SQL and Python. It simulates a simplified music streaming platform similar to Spotify.

It allows users to manage:
- Users
- Artists
- Albums
- Songs
- Playlists

---

## ⚙️ Features
- Add and manage users
- Store artists and albums
- Manage songs linked to albums
- Create playlists
- Add songs to playlists
- Query songs by artist
- View playlists dynamically

---

## 🧱 Tech Stack
- Python 3
- SQLite
- SQL (schema, queries)
- JSON (sample data)

---

## 📁 File Structure
- project.py → main application logic
- schema.sql → database structure
- queries.sql → sample SQL queries
- students.json → sample user dataset
- requirements.txt → dependencies
- DESIGN.md → database design document
